### DevBoard

A modern **developer productivity dashboard built with HTML5 + CSS3 only**.

### Features
- Responsive developer dashboard
- Project showcase
- Skill progress
- Full-stack roadmap
- CSS-only contribution visualization
- Semantic HTML5
- CSS Grid + Flexbox
- No JavaScript
- No Bootstrap
- No Tailwind
- No React

## Structure
```text
HTML/
├── index.html
├── projects.html
├── skills.html
├── roadmap.html
├── activity.html
├── css/
│   └── style.css
└── README.md
```

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## GitHub Pages
Repository → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
